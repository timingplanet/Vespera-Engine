1.0 scope

Vespera 1.0 focuses on a complete Windows/D3D12 path for small real games instead of claiming unfinished platforms or workflows.

Vulkan, Linux, full orthographic 2D world authoring, visual scripting, multiple RmlUi surfaces, and per-entity Lua are post-1.0 work. See 1.0 limitations.

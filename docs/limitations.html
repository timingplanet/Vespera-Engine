Release scope

Vespera Engine 1.0 limitations

These are deliberate 1.0 boundaries, not hidden promises.

Platform

Windows x64 + Direct3D 12. Vulkan and Linux are post-1.0.

2D

The experimental starter is playable screen-space RmlUi + C#. Full orthographic world/editor tooling is post-1.0.

UI

One active RmlUi surface per process; no dedicated visual RML/RCSS layout editor.

Lua

Project-level Start/Update/Stop only. No per-entity Lua components or require modules.

Asset moves

Controlled editor moves preserve supported references. Arbitrary external filesystem moves are not guaranteed recoverable.

Automation

MCP/editor automation is developer-preview and not a frozen 1.x compatibility contract.

Deliberately deferred

Hardware ray tracing, upscalers, visual scripting, Vulkan, Linux, large multiplayer systems, advanced physics, multiple RmlUi surfaces, and complete 2D world authoring are outside the 1.0 release bar.

The source-tree version of this document is docs/LIMITATIONS.md.
